These are R scripts and example data set for archetype identification procedures for binary data using FCA.

* The script 'atsel_v...R' contains the function to select an optimal set of concepts (and some more helpful functions).
  
* The files starting with 'Rural renewal' contain the example data (from Wang et al. (2019) Sustainable Rural Renewal in China: Archetypical Patterns. Ecology and Society 24 (3), https://doi.org/10.5751/ES-11069-240332), and the accompanying R scripts.
  
* The files starting with 'oberlack' contain the example data (from Oberlack & Eisenack (2018) Archetypical Barriers to Adapting Water Governance in River Basins to Climate Change, Journal of Institutional Economics 14 (3): 527–55, https://doi.org/10.1017/S1744137417000509), and the accompanying R scripts.
